## 確定したキャッシュ・履歴・容量管理

- **元動画:** videoIDを識別子として、同じ動画の重複ダウンロードを避ける。
- **変換済データ:** `videoID + 解像度 + FPS + 変換条件`で区別する。異なるFPSやクロップ等の条件を同じ完成キャッシュとして再利用しない。変換条件の表現と保存形式は未決。
- **完成状態:** ダウンロード/変換の途中・失敗したファイルを完成キャッシュにしない。完成データだけを再利用可能な履歴再生対象として扱う。未完データの保存/再開/手動削除の扱いは設計時に決める。
- **履歴表示:** サムネイル、動画タイトル、投稿者/チャンネル名を表示する。表示メタデータもキャッシュし、再選択時には保存済み情報を利用する。
- **再選択:** 完成済みの同じ変換条件があれば再生に再利用する。元動画だけがある場合は、指定FPS等の変換データを作る。元動画・変換済データ・メタデータの完了状態を混同しない。
- **容量管理:** 使用量表示と手動削除を実装する。自動削除しない。削除する対象と範囲を利用者に確認できるようにする。再生中/変換中の対象への削除操作は未決。

3. 使用量の内訳/表示単位、削除対象と範囲（元動画のみ/変換データのみ/両方/履歴情報・サムネイルも含むか）、確認方法。再生/変換中は削除禁止にするか待機させるか等は未決。容量不足時も勝手に既存キャッシュを自動削除しない。
4. 24時間連続再生は要求済み。一動画ループかプレイリストか、新規指定の即切替/現在動画の終了待ち、停止/再開、取得失敗時の扱い。常時運用の起動/再起動方法。
